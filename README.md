A program that writes one short poem about agency — the power to choose and to act — when two agents agree on one plan.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt` (UTF-8, 1–280 characters, deterministic, no network).
